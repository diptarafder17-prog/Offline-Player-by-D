# Offline-Player-by-D 🎵

A lightweight, cyber-themed YouTube music player and playlist manager built with **Flask** and the **YouTube IFrame API**.

## Features
- 🎧 **Embedded YouTube Player**: Seamless audio/video playback via official YouTube IFrame API.
- 📜 **Playlist Persistence**: Save, load, and delete tracks backed by `playlist.json`.
- ⚡ **High Performance**: In-memory caching for zero-latency playlist queries.
- 📱 **Mobile & Pydroid 3 Ready**: Configured to run on local Android environments or browsers.
